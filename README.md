Repositório criado para ser utilizado na aplicação GerenciaFunc, aplicação de gerenciamento de funcionarios.
Esta funcionalidade é especifica para importação de funcionarios via link web.

Instruções: Abra o arquivo funcionarios.JSON altere-o adicionando os funcionarios e informações que deseja, quantos desejar, em seguida clique na opção RAW do arquivo e copie sua URL, por fim cole a URL na parte de importação da aplicação
